# Test audit fault proof

Issue routing: [#151](https://github.com/cbusillo/macos-game-patches/issues/151).

## Question and gates

Do the retained and rewritten tests detect broken behavior while accepting
intended changes to profile paths, target selection and runtime owner metadata?
Does the UI transport reject invalid results without launching a real helper?

Each slice must pass its affected suite, fail under a planted implementation
fault, restore the implementation, and pass again. Faults are temporary edits
in the linked worktree; none may enter a commit or an installed runtime.

## Reproduction

Use Python through `uv run --no-project python`. For lifecycle tests on an
external worktree, create a short disposable fixture root and export
`RUNTIME_FIXTURE_ROOT=/Volumes/Developer-Artifacts/f/151`. Longer fixture paths
can exceed macOS's Unix socket path limit and fail before lifecycle assertions.

Run the affected suites from the repository root:

```sh
uv run --no-project python tools/runtime_profile_test.py
uv run --no-project python tools/runtime_control_test.py
```

For each fault, save the implementation's original bytes, make the replacement
below exactly once, run the named test with `PYTHONPATH=tools` and
`uv run --no-project python -B -m unittest MODULE.CLASS.TEST`, then restore the
original bytes in a `finally` block. Remove that module's generated bytecode
before the invocation to prevent stale cache reuse. Expect an assertion failure
for the stated behavior, rather than an import error or timeout. Verify the
implementation has no Git diff after restoration.

- Owner marker: in `runtime_control.native_bundle_owner_content`, replace
  `return owner_item["content"]` with the checked-in production marker.
  `runtime_control_test.LifecycleTests`'s
  `test_preserved_bundle_owner_content_is_derived_from_contract` must fail
  because the distinct fixture marker disagrees.
- Launcher path: in `runtime_profile.resolve_profile_targets`, return
  `install_root / "FreedomLocomotion.exe"` as the resolved executable.
  `runtime_profile_test.RuntimeProfileTests`'s
  `test_installed_profile_resolves_exact_steam_identity_and_targets` must fail
  because the executable disagrees with `FixtureLauncher.exe`.
- Owned process path: in `runtime_profile.resolve_owned_process`, return the
  production Freedom shipping executable instead of the resolved fixture path.
  The same installed-profile test must fail on the owned executable assertion.
- Owned selection: in `runtime_profile.InstalledProfile.owned_processes`, iterate
  `targets_by_id` instead of `owned_target_ids`.
  `runtime_profile_test.RuntimeProfileTests`'s
  `test_owned_targets_resolve_from_runtime_targets` must fail on IDs/order.

The alternate owner marker, alternate launcher/producer paths and reordered
owned-target subset are successful intended-change controls in the same tests.
Hashes and byte equality on disposable artifacts remain restoration evidence.

## Artifacts and cleanup

Raw baseline, fault and restored-suite logs are kept outside the checkout at
`/Volumes/Developer-Artifacts/task-evidence/macos-game-patches/issue-151-test-audit/`.
Each PR records its exact commands and observed failures. Remove temporary
fixture directories after tests; preserve proof logs for the issue's audit.
No runtime installation, signing identity change, device run or production
operation is part of this audit.
